## 1. Primary Competitor: Silbar Security

**Website:** silbarsecurity.in
**Tech Stack:** Next.js 16 + React 19 + Tailwind CSS v4 + GSAP
**Scale:** ~320+ pages, 200+ city pages, 35 state pages
**Established:** 2018 (Pvt Ltd incorporated 2025)

### What Silbar Does Well
- **Programmatic SEO:** 200+ city pages, 35 state pages — massive local SEO coverage
- **Professional design:** Premium GSAP animations, glass morphism, magnetic buttons
- **Technical execution:** Next.js SSG, JSON-LD on every page, programmatic content generator
- **WhatsApp integration:** Every page has WhatsApp CTA, forms submit via wa.me
- **Trust signals:** ISO certifications, PSARA licensed, Startup India registered, CAPSI member
- **Blog:** Regular WordPress blog with embedded posts
- **Video:** YouTube channel with security industry content
- **GBP:** Multiple Google Business Profiles linked to pages

### Silbar's Weaknesses (Opportunities for PSARA)
- **Niche:** Security services (large, crowded). PSARA can focus on PSARA LICENSING specifically — more targeted.
- **Content depth:** State/city pages use generated content — functional but not deeply researched
- **Video quantity:** Limited video output. PSARA targets 30 videos/month
- **Multi-language:** Mostly English. PSARA adds Hindi/Hinglish content
- **Positioning:** Security agency (sell to end clients). PSARA is consultancy (sell to agency owners)
- **FAQ count:** ~30 FAQs. PSARA targets 55-100

### Silbar's Structure (Copy for PSARA)

```
Core pages (19) → Service pages (12) → Industry pages (20+)
→ State pages (35) → City pages (200+) → Blog (WordPress)
→ Careers, Case Studies, Franchise, Gallery, Clients, CSR
```

PSARA maps to:

```
Core pages (20) → PSARA Guide pages (14) → Service pages (10)
→ State pages (28) → City pages (200+) → Blog (50+)
→ FAQ (55-100) → Resources
```
