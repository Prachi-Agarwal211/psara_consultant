### 2.2 Business Structure Verdict
> **Private Limited Company** is best for security agencies — mandatory for government tenders, provides limited liability, and required for PSARA. LLP is second-best for small agencies.

### 2.3 GST for Security Agencies
- **Rate:** 18% (SAC Code 9985 — Security and investigation services)
- **RCM:** If non-body-corporate (proprietorship/partnership) provides services to registered person, recipient pays GST
- **Best practice:** Register as Pvt Ltd so you charge 18% forward and claim ITC

## 3. WEBSITE BUILD — Anti-Generic Design Rules

From `ai research prompts/` folder analysis — these rules MUST apply to the PSARA website:

### 3.1 NEVER Use (Hard Blocks)
- Inter, Roboto, Poppins, Montserrat, Open Sans, Lato, Raleway fonts
- Pure #000000 or #FFFFFF (use off-black/off-white)
- Default CSS `ease` or `ease-in-out` (use custom cubic-bezier)
- Symmetric 3-column grids (asymmetric or offset only)
- Fade-in as the only reveal technique (use clip-path, transform, scroll-driven)
- Animation on page load for above-the-fold content
- animation-delay (use Intersection Observer instead)
- Default browser link colors
- Blue gradient (#4A90E2 to #50E3C2) — "the AI fingerprint"
- More than 5 colors (3 primary + 1 accent + 1 neutral)

### 3.2 ALWAYS Use (Hard Requirements)
- Variable fonts when available (animate font-weight on scroll)
- clamp() for responsive font sizes
- OKLCH for gradients (prevents muddy dead zones)
- color-mix() for dynamic tinting
- Container queries
- prefers-reduced-motion fallback
- 4.5:1 contrast ratio for text, 3:1 for UI
- Custom cubic-bezier for ALL animations

### 3.3 Anti-Generic — "Remember One Thing" Per Section
| Section | Visitor Must Remember |
|---------|----------------------|
| Hero | "That scroll reveal was insane" |
| Features | "The clip-path animation was unique" |
| About | "The kinetic typography was wild" |
| Services | "The cursor changed shape per section" |
| Testimonials | "The parallax depth was so smooth" |
| Contact | "The magnetic hover was satisfying" |

### 3.4 10-Point AI Detection Test (Apply Before Shipping)
1. Can you describe one thing this component does from memory?
2. Does it feel like royalty-free background music?
3. Show to developer — "Nice template" = fail
4. Symmetric grid, Inter font, fade-in, blue gradient = AI tell
5. Could Figma Sites build this with zero custom code?
6. Show non-coder — "That one thing was insane" = pass
7. Remove logo — still look like YOUR site?
8. More memorable than 5 competitors?
9. Come back in 24 hours — still feel fresh?
10. One sentence why this site is special?
