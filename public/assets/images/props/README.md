# PSARA float props (transparent)

Drop-in decorative assets for section atmosphere. All files are transparent (alpha).

| File | Use |
|------|-----|
| `shield-gold` | Trust / licensing hero moments |
| `wax-seal` | Approval, certificate sections |
| `gavel` | Legal / compliance services |
| `document-scroll` | Filing / paperwork |
| `laurel` | Awards / proof interstitials |
| `ribbon-banner` | Banner base (no text) |
| `ink-pen` | Signature / execution |
| `corner-ornament` | Frame corners |
| `portfolio-binder` | Photoreal binder cutout |
| `seal-and-pen` | Photoreal seal + pen cutout |

Formats: `.svg` (where vector), `.png`, `.webp`.

Wire via `app/components/ui/FloatProps.tsx` — always `pointer-events-none`, desktop-first for dense props so mobile stays clean.
