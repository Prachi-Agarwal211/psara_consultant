## 1. OVERVIEW & CENTRAL FRAMEWORK

**Governing Law:** Private Security Agencies (Regulation) Act, 2005 (PSARA)
**Enforcement Date:** 14 March 2006
**Central Portal:** https://psara.gov.in/
**Ministry:** Ministry of Home Affairs (MHA), Govt. of India
**Central Model Rules:** Private Security Agencies Central Model Rules, 2020

### Key Features:
- PSARA is a **central law** implemented at **state level**
- Each state/UT appoints a **Controlling Authority** (not below Joint Secretary rank)
- License is **state-specific** - one license per state only
- License is **non-transferable**
- FDI up to 49% allowed under approval route (MHA clearance)

### Eligible Entities:
Sole Proprietorship | Partnership Firm | LLP | OPC | Private Limited Company | Association of Persons

## 2. STANDARD FEE STRUCTURE & VALIDITY

### Government Fee Slabs (most states):

| Area of Operation | Fee |
|-------------------|-----|
| One District | Rs 5,000 |
| Up to 5 Districts | Rs 10,000 |
| More than 5 / Entire State | Rs 25,000 |

### Exception:
- **Karnataka:** Entire State fee = **Rs 50,000**

### License Validity:

| Duration | States |
|----------|--------|
| **5 Years** | All except those below |
| **1 Year** | Madhya Pradesh, Chhattisgarh, Uttarakhand |

### Renewal: Apply 45-90 days before expiry. Fee = same as fresh license.

### Penalty for Non-Compliance:
- Imprisonment up to **1 year** AND/OR fine up to **Rs 25,000**

## 3. REQUIRED FORMS

| Form | Purpose |
|------|---------|
| **Form I** | Main application for grant/renewal |
| **Form II** | Antecedent verification (each proprietor/partner/director) |
| **Form III** | Affidavit of non-conviction under Section 6 & compliance Section 9(2) |
| **Form IV** | License certificate (issued by CA) |
| **Form V** | Character & antecedents form for security guard/supervisor |
| **Form VI** | Affidavit by security guard under Section 10(2) |
| **Form VII** | Character & Antecedent Certificate (issued by agency) |
| **Form VIII-XI** | Registers, duty roster, photo ID card |

Note: Some states (e.g., Madhya Pradesh) have additional state-specific forms like Form P.

## 6. CENTRAL MODEL RULES 2020 & RECENT AMENDMENTS

### Model Rules 2020 - Key Changes:
1. **Training:** Min 100 hrs classroom + 60 hrs field training (20 days). Aligned with NSQF.
2. **Verification:** Through CCTNS/ICJS databases. Report valid 5 years. Issued within 15 days.
3. **Digital:** E-sign, online fee payment. No manual police verification at application stage.
4. **Physical Standards:** Detailed fitness & medical requirements for guards.
5. **Records:** Standardized register formats (Forms VIII-XI). Photo ID card (Form XI).

### MHA SOPs (May 2023):
- Streamlined training institute recognition/renewal
- Simplified license processing
- Faster decisions, accountability measures

### 2019 Amendments:
- Electronic databases (CCTNS/ICJS) compulsory for verification
- Electronic payment accepted
- NSQF mandatory from Dec 2019
- Character certificate valid 5 years regardless of employment
- Physical premises verification by CA
- License delivered by speed post within 15 days

## 7. POLICE VERIFICATION PROCESS

### General Process:
1. Form I submitted -> CA initiates verification via local police
2. CCTNS/ICJS database check
3. Physical address verification (residence + office)
4. Report submitted to CA -> NOC issued if clean
5. License granted

### Who is Verified:
Proprietor / All partners / All directors / Principal Officer / Key managerial personnel
